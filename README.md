## 🎯 What is HelloDr?

HelloDr is a full-featured virtual healthcare platform that connects patients with certified doctors faster than you can say "WebMD has convinced me I have a rare tropical disease." Whether you need a quick consultation, want to book an appointment, or just need someone with an actual medical degree to tell you that headache is probably from staring at screens all day - we've got you covered!

Built with PHP, MySQL, and a healthy dose of modern web technologies, HelloDr makes healthcare accessible, convenient, and (dare we say it?) actually pleasant.

## 🚀 Installation & Setup - Get Started in Minutes!

Ready to bring HelloDr to life? Follow these steps, and you'll be up and running faster than you can say "Is it normal for my knee to do this?"

### Prerequisites

Before you begin, make sure you have:
- A local server environment (XAMPP, WAMP, MAMP, or LAMP)
- PHP 7.4 or higher (because we're not savages)
- MySQL 5.7 or higher
- A modern web browser (if you're using Internet Explorer, we need to have a talk)
- Basic knowledge of PHP and MySQL (or a willingness to learn!)

### Step-by-Step Installation

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kawshik-ornob8/HelloDr.git
cd HelloDr
```

#### 2️⃣ Setup Your Local Server

- **Using XAMPP:**
  - Move the HelloDr folder to `C:\xampp\htdocs\` (Windows) or `/Applications/XAMPP/htdocs/` (Mac)
  - Start Apache and MySQL from the XAMPP control panel
  
- **Using WAMP:**
  - Move the HelloDr folder to `C:\wamp64\www\`
  - Start WAMP server

- **Using MAMP:**
  - Move the HelloDr folder to `/Applications/MAMP/htdocs/`
  - Start MAMP server

#### 3️⃣ Create the Database

1. Open your browser and go to `http://localhost/phpmyadmin`
2. Create a new database named `hello_dr`
3. Click on the `hello_dr` database
4. Go to the "Import" tab
5. Click "Choose File" and select the `hello_dr.sql` file from the project root
6. Click "Go" and wait for the import to complete (grab a coffee, you deserve it)

#### 4️⃣ Configure Database Connection

Open the `config.php` file and update it with your database credentials:

```php
<?php
$servername = "localhost";
$username = "root";        // Your MySQL username
$password = "";            // Your MySQL password
$dbname = "hello_dr";      // Database name

// Create connection
$conn = new mysqli($servername, $username, $password, $dbname);

// Check connection
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}
?>
```

#### 5️⃣ Launch the Application

1. Open your web browser
2. Navigate to `http://localhost/HelloDr/`
3. Voilà! You should see the HelloDr homepage
4. Start exploring the platform!

### 🎉 Default Login Credentials

After installation, you can use these default accounts to explore the platform:

**Admin Account:**
- Check the database `admins` table for admin credentials

**Doctor Account:**
- Check the database `doctors` table for doctor credentials

**Patient Account:**
- Register a new patient account through the signup page!

## 📚 How to Use HelloDr

### For Patients

1. **Sign Up**: Create your account on the registration page
2. **Browse Doctors**: Explore our list of qualified healthcare professionals
3. **Book an Appointment**: Select a doctor and choose your preferred time slot
4. **Consult**: Join your video consultation at the scheduled time
5. **Follow Up**: Message your doctor if you have questions
6. **Rate & Review**: Share your experience to help others

### For Doctors

1. **Register**: Sign up as a doctor and complete your profile
2. **Wait for Approval**: Admin will verify your credentials (usually within 24-48 hours)
3. **Set Availability**: Configure your working hours and available slots
4. **Manage Appointments**: View and respond to appointment requests
5. **Conduct Consultations**: Join video calls and provide quality care
6. **Stay Connected**: Respond to patient messages and follow-ups

### For Admins

1. **Login**: Access the admin panel with your credentials
2. **Verify Doctors**: Review and approve doctor registrations
3. **Monitor Activity**: Keep track of platform usage and user behavior
4. **Manage Users**: Handle any user issues or account problems
5. **Generate Reports**: Analyze platform performance and growth
